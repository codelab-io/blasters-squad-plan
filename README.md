# Blasters Squad Plan

Interactive Kerala Blasters FC 2026-27 squad plan — Ashley Westwood's probable XI, visualised.

**Live app:** open `index.html` in a browser (single self-contained file, no dependencies).

## What's inside

- Interactive pitch with the probable **4-4-2** starting XI — tap any player for their card (age, nationality, previous club, role)
- **4-4-2 ↔ 4-3-3** formation toggle
- Full squad **depth chart** (GK / Defence / Midfield / Attack), foreign players badged
- **Foreign-slot tracker** — 5 of 6 filled: Andre Green, James Bolton, Nebojša Kosović, Momo Yansané, Fallou Ndiaye (6th slot open)
- Next fixtures strip and Westwood's tactical notes
